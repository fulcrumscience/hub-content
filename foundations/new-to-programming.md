# New to Programming

Start with Python basics & learn version control early.

> **Tip:** Don't try to learn everything at once. Pick one resource from each category and work through it completely before moving on.

## Python for Science

| Resource | Description | Level |
|----------|-------------|-------|
| [Scientific Computing for Chemists](https://weisscharlesj.github.io/SciCompforChemists/notebooks/introduction/intro.html) | Python fundamentals with science applications | Beginner |
| [MolSSI: Python Scripting CMS](https://github.com/MolSSI-Education/python_scripting_cms) | Molecular Sciences Software Institute curriculum | Beginner–Intermediate |
| [Deep Learning for Chemistry 101](https://github.com/rociomer/dl-chem-101) | Introduction to deep learning methods for chemistry | Intermediate |
