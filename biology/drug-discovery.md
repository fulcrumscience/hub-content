## Datasets

### Compound Libraries & Bioactivity

| Dataset | Description | Size |
|---------|-------------|------|
| [**TDC**](https://tdcommons.ai/) | Drug discovery benchmarks | Various |
| [**MoleculeNet**](http://moleculenet.ai/) | ADMET, toxicity benchmarks | 700K+ molecules |
| [**ChEMBL**](https://www.ebi.ac.uk/chembl/) | Bioactivity data | 2M+ compounds |
| [**BindingDB**](https://www.bindingdb.org/) | Drug-target binding data | 2.6M+ entries |
| [**PDBbind**](http://www.pdbbind.org.cn/) | Protein-ligand affinity | 23K+ complexes |
| [**DrugBank**](https://www.drugbank.com/) | Approved and investigational drugs | 15K+ drugs |
| [**ZINC**](https://zinc.docking.org/) | Virtual screening compounds | 250M+ |

### Drug Response & Screening

| Dataset | Description |
|---------|-------------|
| [**NCI60**](https://dtp.cancer.gov/discovery_development/nci-60/) | Cancer cell line screening |
| [**GDSC**](https://www.cancerrxgene.org/) | Genomics of Drug Sensitivity |
| [**CCLE**](https://sites.broadinstitute.org/ccle/) | Cancer Cell Line Encyclopedia |
| [**CellMinerCDB**](https://discover.nci.nih.gov/cellminercdb/) | Integrated cell line databases |

### Knowledge Graphs

| Dataset | Description |
|---------|-------------|
| [**DRKG**](https://github.com/gnn4dr/DRKG) | Drug Repurposing Knowledge Graph |
| [**DrugMechDB**](https://github.com/SuLab/DrugMechDB) | Drug mechanism database |
| [**CTD**](http://ctdbase.org/) | Chemical-gene-disease associations |
