### Language Models

#### Chemistry & Materials

| Model | Description | Size |
|-------|-------------|------|
| [**ChemBERT**](https://pubs.acs.org/doi/10.1021/acs.jcim.1c00284) | Chemical reaction extraction | Base |
| [**MatSciBERT**](https://arxiv.org/abs/2109.15290) | Materials domain language model | Base |
| [**ChemDFM**](https://arxiv.org/abs/2401.14818) | Chemistry dialogue foundation model | 13B |
| [**ChemLLM**](https://arxiv.org/abs/2402.06852) | Chemical large language model | 7B |

#### Molecule-Language

| Model | Description | Size |
|-------|-------------|------|
| [**MolT5**](https://arxiv.org/abs/2204.11817) | Molecule-language translation | 60M–770M |
| [**MoleculeSTM**](https://arxiv.org/abs/2212.10789) | Multi-modal structure-text model | — |

## Datasets

### Benchmark Suites

| Dataset | Description |
|---------|-------------|
| [**MoleculeNet**](https://moleculenet.org/datasets-1) | Comprehensive benchmark suite with multiple tasks |
| [**TDC**](https://tdcommons.ai/) | Therapeutics Data Commons — drug discovery datasets |
| [**OCHEM**](https://ochem.eu/) | 3.77M records for 689 chemical properties |

### Structure Databases

| Dataset | Description |
|---------|-------------|
| [**ChEMBL**](https://www.ebi.ac.uk/chembl/) | Bioactive molecules with drug-like properties |
| [**PubChem**](https://pubchem.ncbi.nlm.nih.gov/) | Chemical information from 750+ data sources (116M compounds) |

### Property Prediction

| Dataset | Property |
|---------|----------|
| [**AquaSolDB**](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/OVHAW8) | Curated aqueous solubility |
| [**ESol**](https://pubmed.ncbi.nlm.nih.gov/15154768/) | Water solubility for organic small molecules |
| [**Lipophilicity**](https://deepchemdata.s3-us-west-1.amazonaws.com/datasets/Lipophilicity.csv) | Octanol/water distribution coefficients |
| [**Harvard OPV**](https://figshare.com/articles/dataset/HOPV15_Dataset/1610063/4) | Photovoltaic data with quantum-chemical calculations |
| [**Photoswitch Dataset**](https://github.com/Ryan-Rhys/The-Photoswitch-Dataset) | 405 curated photoswitch molecules |

### Bioactivity

| Dataset | Description |
|---------|-------------|
| [**BindingDB**](https://www.bindingdb.org/rwd/bind/chemsearch/marvin/Download.jsp) | 2.6M binding data entries |
| [**Papyrus**](https://doi.org/10.4121/16896406.v3) | Curated bioactivity combining ChEMBL and ExCAPE-DB |
| [**LIT-PCBA**](https://drugdesign.unistra.fr/LIT-PCBA/) | 15 target sets for virtual screening |
| [**MoleculeACE**](https://github.com/molML/MoleculeACE) | Benchmark for activity cliff compounds |
