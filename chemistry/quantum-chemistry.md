## Datasets

### QM Benchmark Datasets

| Dataset | Description |
|---------|-------------|
| [**QM7/QM7b**](http://quantum-machine.org/datasets/) | Small organic molecules with computed properties |
| [**QM8**](http://quantum-machine.org/datasets/) | Electronic spectra and excited state energies |
| [**QM9**](http://quantum-machine.org/datasets/) | 134K molecules with 13 properties from DFT |
| [**ANI-1x/1ccx**](https://qcawebapps.molssi.org/ml_datasets/) | DFT + CCSD calculations (5M + 0.5M structures) |
| [**MD Trajectories**](http://quantum-machine.org/datasets/) | Molecular dynamics simulation data |
| [**SolProp**](https://github.com/fhvermei/SolProp_ML) | 1 million COSMO-RS calculations and solvation data |

### Thermodynamic Data

| Dataset | Description |
|---------|-------------|
| [**BigSolDB 2.0**](https://zenodo.org/records/15094979) | 103,944 solubility values across solvents/temperatures |
| [**FreeSolv**](https://github.com/MobleyLab/FreeSolv) | Experimental and calculated hydration free energies |
| [**ILThermo**](https://ilthermo.boulder.nist.gov/) | Ionic liquid thermodynamic and transport properties |
| [**ThermoML Archive**](https://www.nist.gov/mml/acmd/trc/thermoml/thermoml-archive) | Thermophysical property data (NIST) |
